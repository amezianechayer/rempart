# M6. Remédiation fermée, dérive, FinOps

## Objectif
Boucles L7, L8 et L10.
Ajouts de l'ADR 0013 : import multi-IaC vers OpenTofu (D5) et signaux d'exécution dans la priorisation des chemins d'attaque (D7, partie M6).

## Lire
Skills : `secure-iac-generation`, `safe-autonomy`, `security-graph-attack-paths`.
ADR 0013 (D0, D5, D7) ; ADR 0012 (D2, sujet `graph`).

## Livrables
- Correspondance ressource réelle vers fichier, module et lignes IaC ; import des ressources non gérées.
- `internal/remediate`, `internal/drift`, `internal/finops`.
- Import multi-IaC (ADR 0013 D5), dans l'ordre : état Terraform, puis CloudFormation, puis Pulumi ; les ressources non gérées suivent le même chemin. `internal/remediate/importer` : source lue par le runner seul (liste fermée de champs : type, adresse, identifiant cloud), blocs `import` et `tofu plan -generate-config-out` (plan seulement), HCL passé par la chaîne de validation de L3, vérificateur d'import (aucune action autre que l'import), attributs sensibles remplacés par des références OpenBao, double gestion signalée ; graphe importé dans L2 sous forme graphe (`subject: graph`), corrections par L7 ; CLI `rempart import --from terraform-state|cloudformation|pulumi`.
- Priorisation par signal d'exécution (ADR 0013 D7, partie M6) dans `internal/attackpath` : un signal récent relève la priorité d'un chemin, affiché « signal tiers » ; il ne prouve aucun saut et n'abaisse rien.
- Menaces T131, T132 de l'ADR 0013 soumises à `security-reviewer`.

## Critères d'acceptation
1. Les failles du labo M5 sont corrigées par PR, appliquées via runner, et confirmées résolues par re-scan, sans action manuelle hors approbation.
2. Aucun correctif ne supprime un flux légitime du graphe conçu (vérifié par les vérifications post-déploiement).
3. Dérive provoquée : détectée et réconciliée par PR dans le bon sens.
4. Aucune recommandation FinOps ne viole une politique (test).
5. Import, pour chacune des trois sources, sur le labo : le plan ne contient que des imports (`tofu show -json <plan> | jq '[.resource_changes[] | select(.change.actions != ["no-op"] or (.change.importing | not))] | length'` affiche `0` ; `TestImportPlanImportOnly`).
6. HCL importé sans secret ni expression de gabarit issue d'une valeur importée (`TestImportedHCLHasNoSecret`, `TestImportedHCLHasNoTemplateExpression`) ; état source jamais hors du runner (`TestImportStateNeverLeavesRunner`).
7. Le graphe importé passe par L2 sous forme graphe ; L3 refuse un sujet `graph` (`TestL3RefusesGraphSubject`, garde de T115).
8. Un signal d'exécution relève la priorité d'un chemin du labo, sans prouver de saut ni abaisser de score (`TestRuntimeSignalNeverProvesHop`, `TestRuntimeSignalNeverLowersPriority`).
